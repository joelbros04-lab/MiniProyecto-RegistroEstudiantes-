# Sistema de Registro de Estudiantes

Proyecto desarrollado en C++ para el bootcamp
“Programación de Cero a POO”.

## Funciones del sistema

- Registrar estudiantes
- Mostrar estudiantes
- Calcular promedio general
- Buscar nota mayor
- Buscar estudiante por nombre
- Salir del sistema

## Tecnologías usadas

- C++
- Git
- GitHub
